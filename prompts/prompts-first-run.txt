## 2. Background
The branch adds an opt-in SwiftUI/Liquid Glass presentation behind the compile flag OMI_IOS_SWIFTUI (Dart const iosSwiftUiEnabled; native only when the flag is on AND Platform.isIOS AND supportsIosSwiftUi()). Flutter screens project their state into versioned snapshots of rows (IosNativeSurface, NativeRow, NativeSection, showIosNativeModal, showOmiSheet nativeBuilder, IosNativeEdit, ...) that a SwiftUI renderer draws; callbacks stay in Dart with the existing owners; any invalid row makes the whole screen fall back to the complete Flutter screen. Read first: app/docs/ios-native-ui.md, app/AGENTS.md, all of app/lib/mobile/native_ui/*.dart, and app/ios/Runner/NativeUI/NativeSurfaceContract.swift (to learn exactly which row kinds/values Swift accepts — you cannot run Swift, so mirror its validation rules carefully).
