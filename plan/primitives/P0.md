## Spec
Prerequisite for every batch; adds no row kinds. (1) A snapshot that Swift rejects falls back to Flutter, never to a blank view. NativeSurfacePlatformView.swift: when NativeSurfaceSnapshot.decode(args) throws on iOS 16+, the factory returns a private RejectedNativeSurface. It registers FlutterMethodChannel('com.omi.native_ui/surface/<viewId>'), answers 'update' with FlutterError(code: 'invalid_native_snapshot'), answers 'invalidate' and 'captureImage' with nil and everything else with FlutterMethodNotImplemented, and clears its handler in deinit. Before iOS 16 UnavailableNativeSurface stays. ios_native_surface.dart: _IosNativeSurfaceState gains bool _rejected. _publish() catches PlatformException(code 'invalid_native_snapshot') at any revision, and MissingPluginException while identical(channel, _channel). It then sets _rejected = true, calls unawaited(_invalidate()) and setState. build() returns _fallback() whenever _rejected is set. This is sticky for the State's lifetime and never flaps. Add a debug-only seam, IosNativeSurface.debugCorruptSnapshotForTest (asserts kDebugMode), that publishes version 2 so a host test can prove this path. (2) ios_native_modal.dart showIosNativeModal: invalid or duplicate rows return null instead of throwing ArgumentError (callers already fall back to their Flutter dialog). PlatformException('invalid_native_presentation') from 'present' also returns null. An unknown action, or a value rejected by NativeRow.accepts, returns NativeModalResult(null, {}) with no mutation instead of throwing. Every native presentation goes through one Dart FIFO (a static future tail), so a call waits for the previous presentation to complete before it invokes 'present'. (3) omi_dialogs.dart showOmiConfirmMenu takes the native shortcut only when iosSwiftUiEnabled && Platform.isIOS. Android built with the flag keeps the anchored Flutter menu. (4) NativeSurfaceView.swift: kind 'label' renders row.symbol as a leading SF Symbol through Label(title:icon:), red when destructive; implement this in the label case, not in label() shared by other kinds. In kind 'task', the title Button sends 'open' only when row.options contains 'open'; otherwise the title is static text. (5) IosNativeSurface gains String? loadingLabel; the snapshot sends loadingLabel ?? l10n.loading. (6) New lib/mobile/native_ui/native_asset_image.dart with Future<String?> nativeAssetImageUri(String asset). It accepts only paths under assets/images/ made of letters, digits, '_', '-' and '/', ending in .png, .jpg, .jpeg or .webp, with no '..'. It loads the rootBundle bytes once per process (one memoized Future per path), writes them atomically to <getTemporaryDirectory()>/omi_native_assets/<sha1(asset)>.<ext> and returns Uri.file(path).toString(), which must pass nativeImageUri. It returns null on any failure. This is static bundled artwork only, never user data, so it needs no session cleanup. Device batches pass the URI to the existing imageUri (72x64 thumbnail) and to image rows. (7) ios_native_settings.dart _settingsSymbols gains FontAwesome mappings for Device Settings rows: handPointer hand.tap, lightbulb lightbulb, download arrow.down.circle, rotateLeft arrow.counterclockwise, sdCard sdcard, stethoscope stethoscope, linkSlash link, ban nosign, graduationCap graduationcap, camera camera, gears gearshape.2, hashtag number, industry building.2, fingerprint touchid, barcode barcode. Verify each name exists in iOS 16 SF Symbols. (8) Cross-batch seam in lib/widgets/components/memory_review_card.dart: Future<void> showMemoryReviewSheet(BuildContext context, {required List<MemoryReviewItem> items, required MemoryReviewSource source, String? impressionKey, String? title}). For now it is implemented as showOmiSheet(builder: SingleChildScrollView(child: MemoryReviewCard(...))), which matches today's recap sheet. After P0 the file belongs to chat-structured-messages, which adds a nativeBuilder; maps-recap only calls the function, and its signature is frozen. (9) Host-test scaffolding: move checkNativeHost, nativeViewId, display/UIKit screenshot capture and the row lookup out of integration_test/native_ui_host_test.dart into the library integration_test/support/native_host_harness.dart. It exports: typedef NativeHostCheck = Future<void> Function(WidgetTester, String); void runNativeHostSuite(void Function(NativeHostCheck checkNativeHost) register), which does binding init and keeps the NATIVE_UI_SCREENSHOT_PORT behaviour; int? nativeViewId(WidgetTester, Finder); NativeRow nativeProjectedRow(WidgetTester, String id), which searches toolbar, sections, bottomBar and chat/reader actions of every mounted IosNativeSurface (last match wins); and Widget nativeHostApp(Widget home, {List<SingleChildWidget> providers, Brightness brightness}), which wraps defaultAuditProviders, l10n and theme. native_ui_host_test.dart keeps every existing case and just calls runNativeHostSuite. Each batch adds its own standalone target, integration_test/native_<batch>_host_test.dart, and never edits native_ui_host_test.dart.

## Required tests
Dart: native_surface_rejection_test.dart uses a mocked surface channel. An 'update' answered with invalid_native_snapshot, and one that throws MissingPluginException on the current channel, must each render the fallback, stay there after later rebuilds and leave the channel invalidated. A stale channel's MissingPluginException is ignored. native_modal_queue_test.dart: two concurrent showIosNativeModal calls hit 'present' strictly in sequence. A person name longer than its maximumLength returns null instead of throwing. A forged action or value returns NativeModalResult(null, {}). showOmiConfirmMenu keeps the anchored menu when not on iOS. native_asset_image_test.dart: traversal, absolute, uppercase-extension, unknown-extension and missing assets return null; the same asset returns the same URI and is written once. native_surface_projection_test.dart: loadingLabel reaches the snapshot. Swift (Preview): new fixture rows plus testLabelRowRendersSymbol and testTaskTitleWithoutOpenOptionSendsNothing. Host: native_ui_host_test.dart passes unchanged through runNativeHostSuite, and a debugCorruptSnapshotForTest case proves the complete Flutter fallback renders (not a blank UIView) with no uncaught PlatformException.

## Critic addendum (authoritative; supersedes the spec where they conflict)
- Modal null semantics (critic V8): `null` from showIosNativeModal must always mean "native presentation not used — run the Flutter path". Cancel must be a non-null NativeModalResult(null, {}). Audit EVERY caller of showIosNativeModal / showOmiConfirm* / native modal helpers (grep the whole app/lib) and make each caller fall back to its Flutter dialog on null. Known broken callers that treat null as cancel/handled: _renameNative in lib/pages/conversation_detail/native_conversation_detail.dart (returns true on null, so page.dart skips the rename), _nativeDetailMenu, the detail search modal, and _editNativeSummary in lib/pages/conversation_detail/widgets/summary_tab_native.dart. Fix them (these caller fixes are in P0's scope) and add tests.
- Presentation FIFO: it applies only after the flag + Platform.isIOS + support checks (flag-off/Android calls are never serialised); after waiting, a queued request re-checks context.mounted and the account session before presenting (and returns null → Flutter path if unmounted/session changed); entries can be cancelled (P1's dismissSignal will use this — expose an internal cancellation hook); a presentation that never completes must not block the queue forever: add a bounded watchdog (e.g. the queue advances when the presenting caller's context unmounts or after the Swift side reports completion/invalidation; document the exact rule) and test it.
- Rejection fallback must also cover Home: NativeHomeViewFactory / IosNativeHome must fall back to the classic Flutter Home when Swift rejects the home snapshot (no blank view).
- "Sticky rejection" must survive a parent swapping between classic and native trees (action_items_page.dart and conversations_page.dart rebuild IosNativeSurface under different parents): key the rejection to the surface identity (e.g. a static per-route/per-title registry or an InheritedWidget-scoped flag) so a rejected surface does not flap native→reject→native on every rebuild. Document and test.
