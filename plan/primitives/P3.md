## Spec
Dart (ios_native_surface.dart): new NativeRow kind 'secret'. value is the credential String, 1..4096 chars, every char in 0x21..0x7E (printable ASCII, no whitespace or newline). options must be exactly {'copy': <localized label>}, and accepts(input) is true only for input == 'copy'. imageUri, points, blocks, level, maximumValue, keyboard, maximumLength, indent, swipe ids and graph must all be null or empty. IosNativeSurface gains bool sensitive (snapshot key 'sensitive'). build() falls back when a secret row appears in toolbar, bottomBar, chat, reader or navigation; when there is more than one secret row; when a secret row is present with sensitive false; or when sensitive is combined with publicSurface, chat, reader, navigation, selection or a fill graph. When sensitive, NativeSurfaceController.captureImage returns null without calling the host. showIosNativeModal returns null when any row is 'secret', because the presenter echoes values back. New lib/mobile/native_ui/ios_native_secret.dart: bool nativeSecretValid(String) and Future<void> showIosNativeSecretSheet(BuildContext context, {required String title, String? message, String? warning, required String secretLabel, required String secret, required String copyLabel, required String doneLabel, required VoidCallback onCopy, required Future<void> Function() showClassic}). It calls showClassic when the flag is off, the platform is not iOS, supportsIosSwiftUi() is false or the secret is invalid. Otherwise it captures AuthService.captureSessionSnapshot() and opens showOmiSheet(isDismissible: false, enableDrag: false, nativeBuilder: ...). That page is PopScope(canPop: false) wrapping IosNativeSurface(sensitive: true, title, toolbar [NativeRow('secret_done', doneLabel, symbol 'checkmark')], sections [label message, label warning with symbol exclamationmark.triangle, NativeRow('secret_value', secretLabel, kind 'secret', value: secret, options {'copy': copyLabel}, action: (_) => onCopy())]). Its fallback is a minimal Flutter body (monospace SelectableText of the secret, Copy and Done, using only the passed labels), so the P0 rejection path never loses the one-time key. Done or a session-generation change pops the route. The secret is never logged, never part of a row id and never cached. Swift: the decoder allowlists 'secret' and the top-level sensitive: Bool?; validation mirrors Dart (unicodeScalars all in 0x21...0x7E with count 1...4096, options exactly [copy], sections only, at most one per snapshot, requires sensitive == true). rowView case 'secret': VStack(alignment: .leading) with Text(row.title) in caption semibold secondary; Text(verbatim: value) in .body.monospaced() with .textSelection(.enabled), .privacySensitive() and vertical fixedSize; the subtitle in footnote secondary; and Button { send(row.id, 'copy') } label: Label(copy title, systemImage: 'doc.on.doc') with .buttonStyle(.bordered). The row is exempt from the label-kind disabled rule, and its accessibilityIdentifier is row.id only. When snapshot.sensitive is set, the view observes UIApplication.willResignActiveNotification and didBecomeActiveNotification. While inactive it shows content as .redacted(reason: .privacy) under an ultraThinMaterial overlay, so the app-switcher snapshot hides the key. NativeSurfacePlatformView 'captureImage' returns nil when snapshot.sensitive. withoutContent() resets sensitive to false. NativeModalPresenter.present throws .invalid when any row is 'secret'.

## Required tests
Dart, native_secret_test.dart: a secret that is empty, 4097 chars, contains whitespace or a newline, or contains non-ASCII is invalid. accepts allows only 'copy'. A secret with sensitive false, in the toolbar, doubled, or combined with chat or selection falls back. A modal containing a secret returns null. The routine snapshot JSON contains the secret only inside the secret row value. captureImage returns null on a sensitive surface. showIosNativeSecretSheet calls showClassic when unsupported or invalid, never presents after a session change, and pops on Done. Swift contract: accepts a valid secret in a sensitive snapshot; rejects a non-sensitive snapshot, newline, 4097 chars, a non-copy option, a secret in the toolbar, and two secret rows. Preview fixture 'secret': monospaced value; copy sends exactly 'copy' (never the value); posting willResignActive redacts and didBecomeActive restores; session invalidation clears the value.

## Critic addendum (authoritative)
- Do NOT enable system text selection on the secret value (no .textSelection(.enabled)): copying goes only through the explicit Copy button → Dart OmiClipboard owner.
- showOmiSheet still requires a classic builder; showIosNativeSecretSheet must pass the minimal Flutter body as that builder too, wrapped in OmiSheetScaffold.
