## Used by
device-settings-diagnostics (LED brightness, mic gain), goals-shared-tasks (goal progress), any future labelled setting slider.

## Why
The existing 'slider' kind is the conversation playback scrubber (NativePlaybackSlider in NativeReaderComponents.swift): no visible title, continuous, sends on every drag tick. Settings sliders need a visible title, the current value label, discrete steps and a single commit on release (critic C8). Do not change the existing 'slider' behaviour.

## Spec
Dart: NativeRow gains `double? minimumValue` and `double? step` (projection keys 'minimumValue', 'step'). New kind 'level': value is a finite num with minimumValue (default 0) <= value <= maximumValue; maximumValue required, finite, > minimumValue; minimumValue finite when set; step optional, finite, > 0 and <= (maximumValue - minimumValue), and when set the value must lie on the step grid from minimumValue (|((value-min)/step) - round(...)| < 1e-6) and (max-min)/step must be <= 1000. subtitle is the Dart-formatted, localized current value label (e.g. '75%', 'Level 3'); title is the visible label. accepts(input): num, finite, within bounds, on the step grid when step is set. minimumValue/step are only allowed on kind 'level' (minimumValue also allowed on nothing else). Swift mirrors validation exactly (decode minimumValue/step: Double?).
Rendering (NativeSurfaceView rowView case 'level'): VStack(alignment: .leading) { HStack { Text(title); Spacer(); Text(local value label) .monospacedDigit().foregroundStyle(.secondary) }; Slider(value: local, in: min...max, step: step ?? (max-min)/100, onEditingChanged: { editing in if !editing { send(row.id, rounded value) } }) }. While dragging, the trailing label shows the local numeric value formatted with the snapshot locale (no unit); after the snapshot updates it shows row.subtitle again. Disabled when !enabled or pending. Accessibility: one adjustable element labelled with title, accessibilityValue = subtitle (or the local value while editing), increment/decrement by step (or 10% without step) committing immediately. Optimistic local value is kept until the next snapshot or failure (revert on failure), like other edit controls; it counts as an edit (latest value wins, Save-style waits apply). NativeModalPresenter may reject 'level' (modals don't need it).

## Required tests
Dart native_level_test.dart: valid/invalid matrix (missing max, max <= min, NaN/inf, value off-grid, value out of range, step <= 0, step > range, > 1000 steps, minimumValue/step on another kind); accepts matrix; dispatch passes the number to the action. Swift contract: same matrix. Preview fixture 'level' + UI tests: title and value label visible, dragging does not send until release, release sends exactly one grid value, VoiceOver increment sends one step, large text keeps the title visible, failure reverts the value.
