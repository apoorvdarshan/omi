## Spec
Dart: Future<Set<String>> nativeUiCapabilities() in ios_native_home.dart. It returns {} unless iosSwiftUiEnabled && Platform.isIOS. Otherwise it invokes config 'capabilities', intersects the result with the allowlist {'shortcuts_link'} and caches it for the process; MissingPluginException or null gives {}. NativeRow kind 'shortcuts_link' has value null, no options, no symbol, no action (enabled false) and no imageUri, points or blocks, and is allowed only in sections. Pages emit it only when (await nativeUiCapabilities()).contains('shortcuts_link'). Swift: under #if compiler(>=6.4) && canImport(AppIntents) (the gate SiriBridge uses), the decoder allowlists 'shortcuts_link'. rowView renders ShortcutsLink().shortcutsLinkStyle(.automatic).frame(maxWidth: .infinity, minHeight: 50).accessibilityIdentifier(row.id), exempt from the disabled rule. Outside that branch the kind is rejected. NativeUICapabilities.current, in NativeSurfaceContract.swift, returns ['shortcuts_link'] only inside that branch and only on iOS 16+. AppDelegate's config handler answers 'capabilities' with it. Stable-toolchain builds and the Preview return [].

## Required tests
Dart, native_capabilities_test.dart: flag off or non-iOS returns {} without a channel call; unknown capabilities are filtered out; MissingPluginException returns {}; the result is cached; a shortcuts_link row with a value, options, symbol or action is invalid. Swift contract (Ruby): every kind returned by NativeUICapabilities.current decodes in the same compilation configuration, and 'shortcuts_link' is rejected where it is not compiled. A Siri-toolchain host build is needed to confirm that the Shortcuts app opens; record it as a manual check.

## Critic addendum (authoritative)
- Build gate: the Siri files use only `#if compiler(>=6.4)` (SiriBridge.swift line 1), not `&& canImport(AppIntents)`. Use exactly the same gate.
