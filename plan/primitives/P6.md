## Spec
Dart: new lib/mobile/native_ui/native_graph.dart, which must not import ios_native_surface.dart. It defines NativeGraphNode(id, label, type, x, y, z, fixed), NativeGraphEdge(source, target, label), NativeGraph({nodes, edges, highlighted = const {}, zoom = 1.0, interactive = true, layout = 'fill', double? height, required String accent}) and NativeGraph.placeholder({layout = 'fill', height, required accent}). Projection: {nodes: [{id, label, type, x, y, z, fixed}], edges: [{source, target, label}], highlighted: sorted, zoom, interactive, layout, height, placeholder, accent}, plus nodeIds and valid. NativeRow gains NativeGraph? graph (projection 'graph'), and kind 'graph' holds exactly when graph != null. When interactive, value is '' or a node id, and accepts takes a String that is '' or a current node id; otherwise value is null and accepts takes only null. Validation is identical in Swift. A placeholder has no nodes or edges and interactive false. Otherwise: 1..1024 nodes and at most 4096 edges; node id 1..256 chars and unique; label at most 256 chars; type in {user, person, place, organization, thing, concept}; x, y and z finite with |v| <= 1e6; at most one fixed node, and it must be type user at (0,0,0). Each edge has source != target, both endpoints present, label at most 128 chars, and a unique (source, target, label). highlighted is a subset of the nodes, at most 5 entries, and empty when value is ''. zoom is finite in [0.05, 5]. layout is fill or card. A card has height in [100, 600] and interactive false; a fill graph has height null. At most one fill graph per snapshot. When a fill graph is present, the snapshot has no search, chat, reader, navigation, selection, bottomBar or refresh, and every other section row is label or button; toolbar rows are unrestricted. accent is # followed by 6 hex digits. NativeSurfaceController.captureImage({String? target}): the target must be the id of a current, valid, non-placeholder graph row, otherwise the result is null. It invokes 'captureImage' with {'target': id} under the same session, mounted, channel and 16 MB checks as today. Swift: NativeSurfaceContract.swift decodes and validates Graph, Node and Edge. New NativeGraphView.swift goes in both Runner targets and the Preview project. NativeGraphCanvas is a SwiftUI Canvas that reproduces the Flutter GraphPainter3D math: rotate Y then X; cameraZ 1500; perspective = 1500/(1500 - z) * zoom; alpha = clamp(1 + z/2500); back-to-front order. Nodes get a radial gradient fill with halo rings at 1.8r and 2.5r; edge stroke is 0.8 * scale. Node labels draw when scale > 0.7 && alpha > 0.5 && r > 4, and edge labels when the average scale > 0.6. When a selection exists, non-highlighted elements dim to 15%. Labels get backgrounds in the light scheme. Fixed palette: person #18FFFF, place #00FF9D, organization #FFAB40, thing #FFFF00, concept #448AFF, user = accent. The camera (rotX, rotY, panX, panY, zoom) lives only in NativeSurfaceState.graphCameras[row.id]; it resets when the sorted node-id set changes and is never sent to Dart. graphSizes keeps the last rendered size. Gestures go through a UIViewRepresentable overlay. A one-finger pan rotates at 0.005 rad/pt, a two-finger pan pans, and a pinch zooms within 0.05..5. A tap hit-tests the nearest projected node within max(radius * 1.5, 20)pt, capped at 30pt, and sends (row.id, nodeId), or '' for the background. No other gesture sends anything. Card layout: a fixed-height List row; the whole card is a Button that sends nil. Fill layout: NativeSurfaceView.content switches to a non-scrolling stage. The stage is a VStack of: label rows in snapshot order; the graph with maxHeight .infinity, showing a status overlay for the loading, failed and empty flags; then button rows as NativeGlass buttons. The toolbar is unchanged. Placeholder: a 9-node skeleton that pulses 6 times with .easeInOut, static under accessibilityReduceMotion. Accessibility: the container is labelled with row.title. accessibilityChildren gives one element per node (its label, plus .isSelected when highlighted) whose default action sends the node id, and accessibilityAdjustableAction zooms. NativeSurfacePlatformView 'captureImage' with a target renders NativeGraphCanvas(graph, camera, size) through ImageRenderer at scale min(3, sqrt(16e6/(w*h))) and returns PNG data only if it is at most 16 MB. Without a target, the drawHierarchy path is unchanged. NativeModalPresenter rejects graph rows.

## Required tests
Dart, native_graph_test.dart: one rejection case per rule (counts, duplicate ids, unknown type, non-finite and out-of-range coordinates, a second fixed node, a non-user fixed node, a dangling or self edge, a duplicate edge triple, too many or foreign highlights, highlights with an empty value, zoom bounds, card height and interactivity, a second fill graph, fill with search or other kinds, a bad accent). accepts covers interactive and card. A placeholder must be empty. A capture target that is not a graph row, or a placeholder, returns null. Swift contract: the same matrix. Preview fixtures: 'graph-fill' (a node tap sends its id, a background tap sends '', pinch, rotate and pan send nothing, labels sit above and buttons below at large text, VoiceOver lists the nodes, an adjustable zoom); 'graph-card' (a tap sends nil, List scrolling unaffected); 'graph-placeholder' (pulses, static under Reduce Motion). A unit test in the Preview test target checks that the ImageRenderer capture returns PNG within the 16 MB and 16 MP bounds.

## Critic addendum (authoritative)
- Fill mode loading/error/refresh (critic C1): a fill-graph surface may not set onRefresh. While loading, the page shows NativeGraph.placeholder in fill layout; on error it shows a 'memory_graph_retry'-style button row (button rows are allowed with a fill graph). Make sure the validation allows exactly this.
- Limits: node/edge labels longer than the limits are TRUNCATED by a Dart helper in native_graph.dart (not rejected); graphs with more than 1024 nodes or 4096 edges are not projectable — document that the page then uses the classic Flutter graph, and expose a bool NativeGraph.fits(nodes, edges) helper.
