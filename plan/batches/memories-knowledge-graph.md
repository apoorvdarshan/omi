## Instructions
Common rules: Dart only. MemoriesProvider, KnowledgeGraphApi, the share pipeline and analytics stay the owners, and providers are not edited. Locked memory content never crosses the bridge. Flag-off behaviour is unchanged (memory_graph_empty_state_test stays green). Uses P0, P1 (activity), P2, P4 (swipe) and P6 (graph). Memories list: 1) In memory_item.dart, extract MemoryItem's private statics and handlers to top-level functions with identical behaviour: memoryLedgerSymbol (fact, document, trigger, historical to SF Symbols), memoryTemporalLabel, memoryProvenanceLabel, memoryCanReviewLedgerRow, memoryCanSetUse, openMemoryConversation and openMemoryRow. openMemoryRow routes editable memories to the edit sheet, non-editable ones to the read-only sheet, and locked ones to UsagePage(showUpgradeDialog: true) when showSubscriptionUI, otherwise read-only. In openMemoryConversation, use showIosNativeActivity when it returns a handle, keep the Flutter spinner as fallback, and dismiss in finally. 2) Native rows: NativeRow('memory_<id>', locked ? upgradeToUnlimited : content, kind 'navigation', symbol memoryLedgerSymbol, subtitle slot · provenance · temporal · baseline plus the playbook body), where a tap calls openMemoryRow. Locked rows have no options and no subtitle. Otherwise options are: open; edit and delete when editable; open_conversation when conversationId != null; review_right and review_wrong when reviewable, omitting the verdict already cast; use_allow or use_suppress when belief is enabled, canSetUse and not applying; revert when canRevertSupersededFact and not reverting. enabled is false while that row has a use or revert in flight. swipeTrailing is ['delete'] when editable (deleteMemoryWithUndo). Do not add multi-select; Flutter has none. 3) Sections: 'memory_partial' (label couldNotLoadMemories plus button tryAgain calling loadMemories) when showPartialLoadError. 'memory_history' (label memoryHistoryPartial plus showMore when hasMore) whenever truncated || hasMore. Empty sections mirror the three Flutter empty states and their single action. The reset condition is searchQuery not empty, or memories not empty with an empty filtered list, or filterThisDeviceOnly. Search analytics on submit and clear match Flutter. Knowledge graph: 4) Extract MemoryGraphController (ChangeNotifier) into memory_graph_controller.dart from _MemoryGraphPageState. It holds the simulation, isLoading, error, selectedNodeId and highlightedNodeIds. load({silent}) captures AuthService.captureSessionSnapshot() before awaiting and drops stale results. It provides populate (user-node merge, synthetic user node, edge dedupe, self-loop removal, the _isSameGraph silent-reload rule) and _runLayoutSync. select(String?) toggles, highlights the top 4 nearest neighbours by 3D distance and sends brainMapNodeClicked analytics. The Flutter painter path calls controller.select(hitId), so the classic page is unchanged; keep the resume reload. 5) memory_graph_native.dart: NativeGraph? projectNativeGraph(controller, {layout, interactive, zoom, height}). It maps nodes {id, label, type ('user' for the fixed node, unknown types to concept as _colorForType does), x, y, z, fixed}, the edges, highlighted, and an accent hex from OmiColors.accent, and returns null when the graph is invalid. 6) Full page: when iosSwiftUiEnabled && !preview && !embedded, return KeyedSubtree(key: _nativeShareKey, IosNativeSurface(title memoryGraphTitle, loadingLabel loadingKnowledgeGraph, fallback the current Scaffold, controller _nativeCapture, loading, failed, errorMessage and onRefresh from the controller, empty noKnowledgeGraphYet, toolbar [back; if showShareButton, 'memory_graph_share' (share, square.and.arrow.up, enabled when loaded and not empty)], sections: empty gives labels noKnowledgeGraphYet and knowledgeGraphWillBuildAutomatically; otherwise NativeRow('memory_graph_canvas', memoryGraphTitle, kind 'graph', value selected ?? '', graph: projectNativeGraph(fill, interactive, zoom: widget.initialZoom), action: '' becomes select(null), an id becomes select(id))). If the projection is null, use the classic page. 7) Share on the native path: _nativeCapture.captureImage(target: 'memory_graph_canvas') is decoded to a ui.Image, then the existing watermark, compose, temp-file and Share.shareXFiles code runs inside the usage_share.dart current() session fence, with the popover origin from shareSheetOrigin(_nativeShareKey). A null capture means no share. brainMapShareClicked stays. 8) Preview card in page.dart: show it only when showMindMap && searchQuery.isEmpty && memories.isNotEmpty (this fixes today's native row appearing during search). MemoriesPageState lazily owns a MemoryGraphController with widget.loadGraph. While loading, show NativeRow('memory_graph_preview', memoryGraph, kind 'graph', graph: NativeGraph.placeholder(layout card, height 140)). When loaded, use projectNativeGraph(card, height 140, interactive false, zoom 0.6), with action routeToPage(MemoryGraphPage(trackOpenEvent: false, loadGraph: widget.loadGraph)). An empty graph shows a navigation row (noKnowledgeGraphYet / knowledgeGraphWillBuildAutomatically) with the same action. An error shows a label plus 'memory_graph_retry' (tryAgain, arrow.clockwise). A null projection shows the plain 'memory_graph_open' row, so the list never falls back because of the graph. 9) Onboarding: wrapper.dart passes nativeNavigation: true for kKnowledgeGraphPage too (the progress label and back come from NativeNavigationChrome, and wrapFallback restores the classic step). The step becomes stateful with its own controller and returns IosNativeSurface(title onboardingWhatIKnowAboutYouTitle, fallback the current Column, one section: label onboardingWhatIKnowAboutYouDescription; the graph row by state (loading: placeholder fill; loaded: fill, interactive, zoom 0.72; empty: labels; error: label plus 'onboarding_kg_retry'); and NativeRow('onboarding_knowledge_graph_continue', continueButton) calling OmiHaptics.selection plus onContinue). Never use the surface loading or failed flags here (Continue must stay reachable). A null projection uses the classic step. Do not touch the prebuild or waitForGraphStability, and add no polling. No new strings.

## Critic addendum (authoritative; supersedes the batch spec where they conflict)
- C1: the full graph page must not set onRefresh while showing a fill graph; use NativeGraph.placeholder (fill) while loading and a retry button row on error, so the page never flips between classic and native.
- Graph labels are truncated with the P6 helper; graphs that do not fit (NativeGraph.fits false) use the classic page.
- C13: the usage_share.dart current() fence is a private closure in usage_page.dart; copy the pattern, do not import it.
- Keep frozen signatures MemoriesPage(asRoot:) and MemoryGraphPage(loadGraph:, trackOpenEvent:).
