## Instructions
Common rules: Dart only. SpeakerTagPromptsProvider, PeopleProvider and the speaker-label APIs stay the owners. Clip WAV bytes never cross the bridge; only the 40 derived bar levels do. Flag-off behaviour and speaker_tag_prompt_card_test stay unchanged. native_home_presentation.dart is a part of home/page.dart, which the tasks batch edits: prefix any new private helper with _nativeSpeaker. Uses P0, P1, P2 (Undo stays visible above the sheet) and P4. 1) In native_home_presentation.dart, the 'speakers' alert's showOmiSheet gains nativeBuilder: (_) => const NativeSpeakerReview(), a new widget in speaker_review_native.dart that watches SpeakerTagPromptsProvider and PeopleProvider; its fallback is SpeakerTagPromptCard. Extract _giveAnswer into a top-level giveSpeakerTagAnswer (staging, OmiFeedback.undo, commitPending, haptics, people refresh) shared by both renderers. Rows: toolbar 'speaker_review_close' (xmark) calling provider.close and pop. 'speaker_review_header' label (progress 'n of m') with onVisible calling reportShown. Clip section: 'speaker_review_play' (play.fill or stop.fill) calling togglePlay; 'speaker_review_wave' waveform from the existing waveformLevels(bars: 40), omitted until the clip is played; labels for duration, quoted excerpt and meta; a clip-unavailable label. Question label, with a person avatar only through nativeImageUri. Candidate buttons 'speaker_review_candidate:<index>' (title name, level matchLevel, symbol pin when pinned), mapped to the candidate list captured in the projection. Answer buttons 'speaker_review_answer:<yes|me|not_me|someone|not_a_person|skip>' per prompt kind. Answered and finished labels with level confidenceLevel(person.confidence), plus checkmark.circle.fill when committed. First-time toggle 'speaker_review_save_voices' calling setSaveOtherVoiceProfiles(fromFirstPrompt: true). Hint footers per kind. 2) showSpeakerPicker gains a native path: a second showOmiSheet nativeBuilder with IosNativeSurface search over local query state. Sections: That's me / Not a person when offered; Add '<query>' (2..40 chars and not an exact match) or New person...; I don't know when allowed; closest voices with level meters and pins; everyone A-Z. It excludes excludePersonId and optimistic people and returns the same SpeakerPickerChoice. New-person name uses a guarded showIosNativeModal text loop (maximumLength 40; a validation label re-presented when the name is outside 2..40 chars; the person_name_dialog idiom). A null result uses _NameDialog. 3) earlier_voice_matches_sheet.dart: showEarlierVoiceMatchesSheet gains nativeBuilder EarlierVoiceMatchesList(native: true): title alsoTitle(personName), toolbar close, and one NativeSection 'voice_match:<index>' per open match (an index into the State's _open list, never a server id). Each section has: a when label (day header plus talk time); play (play.fill) calling _play; yes (checkmark, subtitle saving while saving) and no (disabled while saving) calling _answer. alsoBody goes in the first section's footer. Actions resolve the match from the current _open list; a stale one is a no-op. Pop when _open is empty. Playback and temp files stay in Dart. 4) transcript_tab.dart _publishNativePresentation: add 'detail_transcript_heading' (label, same text and count as _TranscriptHeading), and when _hasUnnamedVoice add 'detail_unresolved_notice' (info.circle) calling showOmiAlert(title unresolvedSpeakersTitle, message unresolvedSpeakersMessage). No new strings.
